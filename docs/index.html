Check a solar installer's license before you sign anything.

Every state licenses solar and electrical contractors differently, and several states have no dedicated "solar installer" category at all — meaning a real installer can be licensed under a generic electrical or building classification with nothing marking them as solar-specific. This site cross-references each state's own public licensing records so you can look a contractor up directly, rather than trusting a website or a doorstep pitch.

How this works

  1. Source — each state's contractor licensing board publishes some form of public record: a licensee roster, a disciplinary ledger, or both.
  2. Cross-reference — where a state has no dedicated solar classification, real installers are often licensed under an unrelated category (usually "Electrical Contractor" or a general building license) with nothing marking them as solar. This site checks against known solar installer names to catch those cases rather than trusting a state's classification labels alone.
  3. Flag, honestly — where a state's data can confirm a contractor's current status or discipline history, this site shows it. Where it can't yet — no disciplinary source has been built for that state, or a name-match hasn't been reviewed by a person — this site says so plainly rather than implying a clean record it hasn't actually checked.

This site cross-references public licensing, disciplinary, and registration records published by each state's contractor licensing board. It is not affiliated with, endorsed by, or operated on behalf of any state agency. Data reflects what each agency had published as of the retrieval date shown on each page and is not a substitute for confirming a contractor's status directly with the relevant state board before hiring.
